

Un-stage (Staging => Working directory)

git restore -- staged . => restore toan bo tu staging ve working directory
git restore -- staged file_1 file _2

GIT - un-commit (Repo -> Staging)
Đưa nội dung commit cuối về staging
git reset --soft HEAD~1

Đưa nội dung commit cuối về working directory
git reset HEAD~1

**Commit đầu tiên không thể bị reset
**nếu muốn reset => xóa thư mục .git đi rồi init lại

**ghi đè message của commit hiện tại:
git commit --amend  -m'new message'
